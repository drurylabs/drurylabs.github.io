loom

loom is a personal tool that keeps Gmail filters in text files. It runs on its owner's computer, from the command line. It is not a service, and it is not for sale or for public use.

What it does

loom reads the filters and labels of a Gmail account, and writes them to a file. When its owner changes the file, loom creates and deletes filters in Gmail so that Gmail matches the file. On request, it also applies the labels of a filter to the mail that is already in the account.

Access to Google data

loom uses the Gmail API with two scopes:

  • gmail.settings.basic, to read and change the filters.
  • gmail.modify, to read the mail, make labels, and change the labels of messages. loom never deletes mail for good.

The privacy policy says how loom treats this data.
